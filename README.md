# Biocluster data management

This repository is for the data management of the biocluster using the `dmanage.igb.illinois.edu` virtual machine (VM). This repository contains scripts for scanning user directories, collecting file metadata, and generating summary statistics. The scripts are designed to process large-scale directory structures and produce detailed reports.

## Overview

This project aims to streamline and manage data efficiently within the biocluster environment. This includes data storage, retrieval, and processing tasks that are essential for the smooth operation of the biocluster.

---

## Directory Structure

### **1. `src/`**
This directory contains all the Python scripts used for scanning, and processing raw data.
The processed data will be stored at `/data/scan_output/` directory.
The output directory structure will be `gpfs_<timestamp>`, eg. `gpfs_20250407`

| File Name            | Description                                                                 |
|----------------------|-----------------------------------------------------------------------------|
| `run_scans.py`       | Combines scans for users, labs, and groups into a single unified process.   |
| `lab_scan.py`        | Scans directories for labs and generates metadata files.                   |
| `group_scan.py`      | Scans directories for groups and generates metadata files.                 |
| `user_scan.py`       | Scans directories for users grouped alphabetically (e.g., `a-m`, `n-z`).   |
| `scan_utils.py`      | Contains utility functions used by scanning scripts for common operations. |

---
### **2. scripts**
Scripts used for processing and summarizing raw data statistics.
Input data are the scan output files at `/data/scan_output/`.
Output will be stored at `results/`.

| Script Name            | Description                                                                 |
|----------------------|-----------------------------------------------------------------------------|
| `summarize_stat.py`  | Processes most recent folder containing `users.csv` and `files.csv` to generate summary statistics to `results/`.       |
| `track_total.py`     | Tracks and summarizes total storage usage across all groups.               |

---
### **3. `results/`**
This directory contains the output files generated by the scripts. Each scan run creates a subdirectory named after the timestamp of the scan.

| Subdirectory/File Name         | Description                                                                 |
|--------------------------------|-----------------------------------------------------------------------------|
| `<timestamp>/`         | Subdirectory for a specific scan run, named after the timestamp.            |
| `<timestamp>/user_statistics.csv`          | Summary of user activity and file statistics.                               |
| `<timestamp>/monthly_user_statistics.csv`  | Aggregated statistics grouped by year and month.                           |
| `running_summary.csv`          | Aggregated storage usage across all groups over time.                      |

## Scripts Overview

### **1. `src/run_scans.py`**
- Combines scans for users, labs, and groups into a single unified process.
- Generates two output files to `gpfs_<timestamp>`:
  - `users.csv`: Contains metadata about each user directory.
  - `files.csv`: Contains metadata about individual files in the directories.

### **2. `src/lab_scan.py`**
- Scans directories for labs.
- Generates two output files to `lab_<timestamp>`:
  - `users.csv`: Contains metadata about each lab directory.
  - `files.csv`: Contains metadata about individual files in the lab directories.

### **3. `src/group_scan.py`**
- Scans directories for groups.
- Generates two output files to `group_<timestamp>`:
  - `users.csv`: Contains metadata about each group directory.
  - `files.csv`: Contains metadata about individual files in the group directories.

### **4. `src/user_scan.py`**
- Scans directories for users grouped alphabetically (e.g., `a-m`, `n-z`).
- Generates two output files to `a-z_<timestamp>`:
  - `users.csv`: Contains metadata about each user directory.
  - `files.csv`: Contains metadata about individual files in the user directories.

### **5. `summarize_stat.py`**
- Processes the `users.csv` and `files.csv` files generated by the scanning scripts.
- Produces summary statistics and generates the following output files to `results/`:
  - `user_statistics.csv`: Summary of user activity and file statistics.
  - `monthly_user_statistics.csv`: Aggregated statistics grouped by year and month.

### **6. `track_total.py`**
- Tracks and summarizes the total storage usage across all groups (users, labs, and groups).
- Generates a `running_summary.csv` file that aggregates storage usage over time.

### **7. `scan_utils.py`**
- Contains utility functions used by the scanning scripts to perform common operations, such as:
  - File and directory validation.
  - Helper functions for processing file metadata.
  - Functions for handling date and time conversions.

## Output File Structures

### **1. `users.csv`**
Processed data file at `/data/scan_output`.
Generated by `run_scans.py`, `lab_scan.py`, `group_scan.py`, and `user_scan.py`.

| Column Name       | Description                                                                 |
|-------------------|-----------------------------------------------------------------------------|
| **ID**            | Unique identifier for the user or directory.                               |
| **NetID**         | The name of the user, lab, or group (e.g., `user1`, `lab1`, `group1`).      |
| **Group**         | The group or center name (e.g., `labs`, `groups`, `a-m`, `n-z`).           |
| **ScanTime**      | Time taken to scan the directory (in seconds).                             |
| **SkipHidden**    | Whether hidden files were skipped during the scan (`True` or `False`).     |
| **TotalFiles**    | Total number of files in the directory.                                    |
| **TotalSizeBytes**| Total size of all files in the directory (in bytes).                       |
| **LastModified**  | Last modification date of the directory.                                   |
| **AccessDate**    | Last access date of the directory.                                         |
| **CreationDate**  | Creation date of the directory.                                            |

---

### **2. `files.csv`**
Processed data file at `/data/scan_output`.
Generated by `run_scans.py`, `lab_scan.py`, `group_scan.py`, and `user_scan.py`.

| Column Name       | Description                                                                 |
|-------------------|-----------------------------------------------------------------------------|
| **ID**            | Unique identifier for the user or directory.                               |
| **NetID**         | The name of the user, lab, or group (e.g., `user1`, `lab1`, `group1`).      |
| **Path**          | Full path to the file.                                                     |
| **Name**          | Name of the file.                                                          |
| **SizeBytes**     | Size of the file (in bytes).                                               |
| **LastModified**  | Last modification date of the file.                                        |
| **AccessDate**    | Last access date of the file.                                              |
| **CreationDate**  | Creation date of the file.                                                 |

---

### **3. `user_statistics.csv`**
Statical results used in report and visualization, stored at corresponding subdirectories with timestamp in `results/`.
Generated by `summarize_stat.py`.

| Column Name          | Description                                                                 |
|----------------------|-----------------------------------------------------------------------------|
| **ID**               | Unique identifier for the user or directory.                               |
| **NetID**            | The name of the user, lab, or group (e.g., `user1`, `lab1`, `group1`).      |
| **Group**            | The group or center name (e.g., `labs`, `groups`, `a-m`, `n-z`).           |
| **LastModified**     | Last modification date of the user's directory.                            |
| **AccessDate**       | Last access date of the user's directory.                                  |
| **TotalFiles**       | Total number of files in the user's directory (from `users.csv`).          |
| **TotalSizeBytes**   | Total size of all files in the user's directory (from `users.csv`).        |
| **InactiveFileCount**| Number of files not modified in the last 6 months.                        |
| **SmallFileCount**   | Number of files smaller than 1KB.                                          |
| **LargestFileSize**  | Size of the largest file for the user (in bytes).                         |
| **AverageFileSize**  | Average size of all files for the user (in bytes).                        |

---

### **4. `monthly_user_statistics.csv`**
Statical results used in report and visualization, stored at corresponding subdirectories with timestamp in `results/`.
Generated by `summarize_stat.py`.

| Column Name          | Description                                                                 |
|----------------------|-----------------------------------------------------------------------------|
| **ID**               | Unique identifier for the user or directory.                               |
| **NetID**            | The name of the user, lab, or group (e.g., `user1`, `lab1`, `group1`).      |
| **YearMonth**        | The year and month of the file activity (e.g., `2025-04`).                 |
| **TotalStorageUsage**| Total size of all files for the user in the given month (in bytes).        |
| **FileCount**        | Total number of files for the user in the given month.                     |

---

### **5. `running_summary.csv`**
Statical results used in report and visualization, stored at `results/`.
Generated by `track_total.py`.

| Column Name          | Description                                                                 |
|----------------------|-----------------------------------------------------------------------------|
| **Group**            | The group or center name (e.g., `Users`, `Labs`, `Groups`, `Total`).       |
| **TotalSizeTB**   | Total size of all files for the group (in terabytes).                          |
| **Date**             | The date of the scan (based on folder modification time).                  |
| **Timestamp**        | The timestamp when the summary was generated.                              |

## How to Run the Scripts

1. **Run Scans**:
   - Use `run_scans.py` to scan all user, lab, and group directories:
     ```bash
     python src/run_scans.py
     ```

2. **Summarize Statistics**:
   - Use `summarize_stat.py` to process the generated `users.csv` and `files.csv` files:
     ```bash
     python summarize_stat.py
     ```

3. **Track Total Usage**:
   - Use `track_total.py` to generate a running summary of storage usage:
     ```bash
     python track_total.py
     ```

## Notes
- Ensure the directory paths in the scripts (e.g., `/gpfs/a-m/`, `/gpfs/labs/`) are correctly configured for your environment.
- The scripts are designed to handle large-scale directory structures but may require adjustments for memory usage or performance in extremely large environments.
